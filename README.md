This project prepares ETL pipeline based on databricks notebooks in azure data lake.
It is basically fecthing all race details of formula one since 1950s and loading in raw containes, then i am transforming and cleaning data based on certain requirements 
and then that cleaned data is being processed to analyze further with aggregations etc using pySpark for presentation layer.
Its basically getting dominant teams, drivers across several years and visualizing that via charts from data bricks notebooks itself.

technologies user : 
Medelion architecture for ETL using databricks and azure
Transformation using pySpark
incremental load architecture
